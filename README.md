# Site Agrinho 2026
Projeto escolar para o Concurso Agrinho 2026, categoria Programação.

# Tema
Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.

# Objetivo
O site apresenta ideias sobre agricultura sustentável, mostrando como a produção rural pode usar tecnologia, conservar recursos naturais e reduzir desperdícios.

# Tecnologias utilizadas
HTML para a estrutura da página.
CSS para o visual, o layout responsivo e a organização dos cartões.
JavaScript para a calculadora de atitudes sustentáveis e o quiz.
Como usar
Abra o arquivo index.html no navegador.

# Arquivos principais
index.html: página principal.
style.css: estilos do site.
script.js: interações em JavaScript.
campo-sustentavel.png: imagem principal do projeto.
# Observação
A imagem principal foi criada para este projeto e não usa logotipos oficiais.
